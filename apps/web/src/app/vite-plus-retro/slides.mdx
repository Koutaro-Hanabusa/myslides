<PersonalHeadingSlide>

そもそも Vite+ って？

</PersonalHeadingSlide>

<PersonalContentSlide title="Vite+ とは">

- 2026/3/13 に公開された **統合ツールチェイン**（VoidZero 製）
- テスト / lint / フォーマット / タスク実行 / Node 管理を **`vp` ひとつ**に束ねる
- 中身は Vite / Vitest / Oxlint / Oxfmt / tsdown /vite task
- ただし、**まだ α 版**

</PersonalContentSlide>

<PersonalContentSlide title="なぜ統合ツールチェイン？">

- 他の言語では統合ツールチェインが当たり前（Cargo, Go …）
- JS は **ツールが乱立**してバラバラになりがち
- その断片化を解決することができるのが Vite+

</PersonalContentSlide>

<PersonalHeadingSlide>

どこに導入した？

</PersonalHeadingSlide>

<PersonalContentSlide title="社内デザインシステム">

- 社内で **デザインシステム**を作っている
- 構成は **Vite + Vitest + Oxlint + Oxfmt** のモノレポ（タスクランナーは Turborepo）
- → Vite+ が束ねる範囲と **ほぼ重なっていた**

</PersonalContentSlide>

<PersonalHeadingSlide>

公開10日で移行した話

</PersonalHeadingSlide>

<PersonalContentSlide title="3/13 → 3/24">

- **3/13** Vite+ 公開
- **3/24** もう移行完了 → わずか **10日ちょっと**
- 「α版をもう本番に入れたの？」と思いますよね

</PersonalContentSlide>

<PersonalContentSlide title="なぜ飛び込めた？">

- まだ **大々的には使っていなかった**（リプレイス後に本格運用する想定だった）
- 元から **ほとんどのツールが Vite+ の範囲内**だった
- 面白そう、でも α 版…と **躊躇**していた
- マネージャー「**ビルドできればよくない？**」→ 確かに、で踏み切った

</PersonalContentSlide>

<PersonalHeadingSlide>

実際どうだった？

</PersonalHeadingSlide>

<PersonalContentSlide title="良かった① 設定が一箇所に">

<CodeBlock lang="text" code={BEFORE_AFTER_CONFIG} />

- `vite.config.ts` に **設定をまとめて書ける**のが最高だった
- テストも lint もタスクも **同じ場所**で完結する

</PersonalContentSlide>

<PersonalContentSlide title="良かった② vp task が強力">

- `vp` の **task** 機能がなかなか強力（まだ使いこなせてないけど）
- Turborepo 的なタスク実行を **Vite+ の中**で賄える感触

</PersonalContentSlide>

<PersonalContentSlide title="良かった③ ライブラリモード">

- デザインシステムは **ライブラリ**として配布する
- その **ライブラリモードの設定も簡単**だった

</PersonalContentSlide>

<PersonalHeadingSlide>

もちろん辛みもあった

</PersonalHeadingSlide>

<PersonalContentSlide title="辛かった① lefthook が壊れた">

- `vp` への移行時、**lefthook** を使っていると pre-commit の設定が弾かれる
- 気づかず **pre-commit が壊れていた** → 自分で設定を直す必要があった

</PersonalContentSlide>

<PersonalContentSlide title="辛かった② Astro が壊れがち">

- 関連で **Astro が壊れがち**（astro のメジャー移行などで都度対応した）

</PersonalContentSlide>

<PersonalContentSlide title="辛かった③ AI が vp を知らない">

- **AI が `vite+` / `vp` コマンドを知らない**ことが多い
- α版ゆえ学習データに無く、提案が外しがち

</PersonalContentSlide>

<PersonalContentSlide title="まとめ">

- 公開直後の α版でも、**範囲が自分たちの構成と重なれば**爆速で乗れる
- 設定が一箇所に集約される体験は **普通に良い**
- α版なので **壊れる前提**で、lefthook / Astro / AI には注意
- 気になってる人は、**一回触ってみてほしい**

</PersonalContentSlide>
