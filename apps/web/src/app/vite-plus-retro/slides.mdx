<PersonalHeadingSlide>

実際どうだった？

</PersonalHeadingSlide>

<PersonalContentSlide title="良かった① 設定が一箇所に">

<CodeBlock lang="ts" code={ALL_IN_ONE_CONFIG} />

- `vite.config.ts` の `defineConfig` に **設定が全部同居**
- test / staged / fmt / run / lint が **1ファイル**で完結
- `vp lint` だけで **type linting**（oxlint-tsgolint）まで実行

</PersonalContentSlide>

<PersonalContentSlide title="良かった② Vite Task (vp run)">

<CodeBlock lang="ts" code={VP_TASK_CONFIG} />

- `-r` で **全 workspace を依存順に実行**
- **モノレポでも問題なく動作**
- Turborepo 的なタスク実行を **Vite+ の中**で完結

</PersonalContentSlide>

<PersonalContentSlide title="良かった②' cache があると爆速">

<CodeBlock lang="text" code={VP_TASK_CACHE_LOG} />

- 使ったファイルを **自動追跡** → 変化なしなら **実行せずリプレイ**
- 実測で **4/5 cache hit・27.38s 短縮**
- 詳しくはこちらがとても参考になります
  - https://zenn.dev/herp_inc/articles/strange-task-runner

</PersonalContentSlide>

<PersonalContentSlide title="良かった③ ライブラリモード = vp pack">

<div className="grid grid-cols-2 gap-4">
  <CodeBlock lang="ts" code={LIBRARY_MODE_CONFIG} />
  <CodeBlock lang="text" code={PACK_SIZE_DIFF} />

- `dts: true` の1行で型定義（**`vite-plugin-dts` 不要**）、React 系は **external 扱い**
- rollup → **tsdown** で gzip **ESM 117KB → 36KB（約1/3）**

</PersonalContentSlide>

<PersonalContentSlide title="良かった④ 個別ツールが要らない">

<CodeBlock lang="ts" code={STAGED_HOOKS_CONFIG} />

- git hooks も **`vp` 同梱**（`staged` に書くだけ）→ **husky / lefthook 不要**
- 独自の pre-commit は **`.vite-hooks/`** で対応
- Node も **`.node-version` だけ**（今回の用途では mise / volta 不要）

</PersonalContentSlide>

<PersonalHeadingSlide>

もちろん辛みもあった

</PersonalHeadingSlide>

<PersonalContentSlide title="辛かった① lefthook使用時にmigrateされない">

- `vp migrate` 時、**lefthook** は自動移行されず警告のみ
- 気づかず **pre-commit が壊れていた** → 設定を手動修正
- 仕様（RFC: `warns and skips`）。自動移行は **husky / lint-staged のみ**

</PersonalContentSlide>

<PersonalContentSlide title="辛かった② Astro がよく壊れた">

- 直後に **Astro 6 へ手動移行**（#198）
- `core@0.1.14` で Astro 互換リグレッション → **0.1.15 で解消**
- `overrides.vite` が Astro 内部の Vite まで置換 → **Release 失敗**

  →AstroV7でVite8がデフォになったり、同じCloudflareになったことで上手いこと行くことに期待

</PersonalContentSlide>

<PersonalContentSlide title="辛かった③ AI が vp を知らない">

- **AI が `Vite+` / `vp` を知らない**ことが多い
- α版ゆえ学習データに無く、提案を外しがち
- **`npx` で実行しがち**

</PersonalContentSlide>

- かなり強力なツール → **ここに全部賭ける価値あり**
- 特に **新規リポジトリは Vite+ 一択**かもしれない
  - とはいえα版なので注意！
