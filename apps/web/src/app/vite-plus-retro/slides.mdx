<PersonalContentSlide title="Vite+ とは">

- 2026/3/13 に公開された **統合ツールチェイン**（VoidZero 製）
- テスト / lint / フォーマット / タスク実行 / Node 管理を **`vp` ひとつ**に束ねる
- 中身は Vite / Vitest / Oxlint / Oxfmt / tsdown /vite task
- ただし、**まだ α 版**

</PersonalContentSlide>

<PersonalContentSlide title="Vite+が解決する課題">

- 他の言語では統合ツールチェインが当たり前
- JS は **ツールが乱立**してバラバラになりがち
- その断片化を解決することができるのが Vite+

</PersonalContentSlide>

<PersonalHeadingSlide>

実際どうだった？

</PersonalHeadingSlide>

<PersonalContentSlide title="良かった① 設定が一箇所に">

<CodeBlock lang="ts" code={ALL_IN_ONE_CONFIG} />

- `vite.config.ts` の `defineConfig` に **設定が全部同居**するのが最高だった
- test / staged / fmt / run / lint が **同じ場所**で完結する
- `vp lint` だけで **type linting**（oxlint-tsgolint）まで走るのも地味に嬉しい

</PersonalContentSlide>

<PersonalContentSlide title="良かった② Vite Task (vp run)">

<CodeBlock lang="ts" code={VP_TASK_CONFIG} />

- `-r` で **全 workspace を「依存順」に実行**（既定で最大4並列）
- **モノレポでも問題なく動いた**（base / business / config / mcp / ui-preview）
- Turborepo 的なタスク実行を **Vite+ の中**で賄える

</PersonalContentSlide>

<PersonalContentSlide title="良かった②' cache があると爆速">

<CodeBlock lang="text" code={VP_TASK_CACHE_LOG} />

- コマンドが **使ったファイルを自動追跡** → 変化なしなら**実行せずリプレイ**
- 実測で **4/5 cache hit・27.38s 短縮**（2回目以降は差分だけ走る）
- Astro の ui-preview だけは入力を書き換えるので**正直キャッシュ外**

</PersonalContentSlide>

<PersonalContentSlide title="良かった③ ライブラリモード = vp pack">

<div className="grid grid-cols-2 gap-4">
  <CodeBlock lang="ts" code={LIBRARY_MODE_CONFIG} />
  <CodeBlock lang="text" code={PACK_SIZE_DIFF} />
</div>

- `dts: true` の1行で型定義（**`vite-plugin-dts` 不要**）、react 系は **自動 external**
- 旧 **Vite build.lib（rollup）→ tsdown** で gzip **ESM 117KB → 36KB（約1/3）**

</PersonalContentSlide>

<PersonalContentSlide title="良かった④ 個別ツールが要らない">

<CodeBlock lang="ts" code={STAGED_HOOKS_CONFIG} />

- git hooks も **`vp` 同梱**（`staged` に書くだけ）→ **husky / lefthook 不要**
- 独自の pre-commit も **`.vite-hooks/`** で仕込める
- ついでに **Node も `.node-version` だけ**（mise / volta 不要）も地味に楽

</PersonalContentSlide>

<PersonalHeadingSlide>

もちろん辛みもあった

</PersonalHeadingSlide>

<PersonalContentSlide title="辛かった① lefthook が壊れた">

- `vp` への移行時、**lefthook** を使っていると pre-commit の設定が弾かれる
- 気づかず **pre-commit が壊れていた** → 自分で設定を直す必要があった

</PersonalContentSlide>

<PersonalContentSlide title="辛かった② Astro が壊れがち">

- 関連で **Astro が壊れがち**（astro のメジャー移行などで都度対応した）

</PersonalContentSlide>

<PersonalContentSlide title="辛かった③ AI が vp を知らない">

- **AI が `vite+` / `vp` コマンドを知らない**ことが多い
- α版ゆえ学習データに無く、提案が外しがち

</PersonalContentSlide>

<PersonalContentSlide title="まとめ">

- 公開直後の α版でも、**範囲が自分たちの構成と重なれば**爆速で乗れる
- 設定が一箇所に集約される体験は **普通に良い**
- α版なので **壊れる前提**で、lefthook / Astro / AI には注意
- 気になってる人は、**一回触ってみてほしい**

</PersonalContentSlide>
