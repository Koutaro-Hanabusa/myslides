実際どうだった？

<PersonalContentSlide title="良かった① vp migrate が最高">

- 既存プロジェクトを Vite+ に移行するための スタート地点
- 依存関係・import・設定ファイル・scripts を まとめて更新
- hooks・AI agent・エディタ設定のセットアップにも対応

</PersonalContentSlide>

<PersonalContentSlide title="良かった② 設定が一箇所に">

<CodeBlock lang="ts" code={ALL_IN_ONE_CONFIG} />

- test / staged / fmt / run / lint を `vite.config.ts` に集約
- hooks は `staged`、Node は `.node-version` で管理
- `vp lint` で type linting（oxlint-tsgolint）まで実行

</PersonalContentSlide>

<PersonalContentSlide title="良かった③ キャッシュがあると爆速">

<CodeBlock lang="text" code={VP_TASK_CACHE_LOG} />

- 使ったファイルを 自動追跡 → 変化なしなら 実行せずリプレイ
- 実測で 4/5 cache hit・27.38s 短縮
- 詳しくはこちらがとても参考になります
  - https://zenn.dev/herp_inc/articles/strange-task-runner

</PersonalContentSlide>

<PersonalContentSlide title="辛かった② Astro のビルドが壊れた">

- Astro 6 は Vite 7 前提。`overrides.vite` で Vite+ の Vite 8 系に置換
- dev-toolbar が使う esbuild API の互換処理で `Not implemented` が発生し、ビルド失敗していた
- override を外し、Astro が使う Vite 7 に戻して復旧
- その後 Astro 7 beta（Vite 8）と Vite+ 0.1.24 へ更新

</PersonalContentSlide>

<PersonalContentSlide title="最小構成で再現して比較">

| 7.0.0-beta.3 | 0.1.19               | 成功                      |
| 7.0.0-beta.3 | 0.1.24               | 成功                      |

**この最小構成では、Vite+ 0.1.19 のまま Astro 7 beta へ更新すると成功**
